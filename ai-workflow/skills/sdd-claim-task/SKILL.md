# Working on a Task

Read and follow, in order:

1. [overview.md]({{AI_WORKFLOW_DOCS_DIR}}/task-workflow/overview.md): the `sdd` CLI, modes and layout.
2. [working.md]({{AI_WORKFLOW_DOCS_DIR}}/task-workflow/working.md): what each request implies, and the steps.

Don't load the planning docs unless the task needs re-planning.

If `sdd root` fails, the project doesn't use the task workflow: say so and stop. Don't set it up or fall back to an ordinary branch-and-implement flow under this skill.
